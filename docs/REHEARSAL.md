# Rehearsal script (step 8)

Run at home on the laptop and projector, in order. Each part has a pass line and the evidence that proves it (VER-07). Send the photos and problem reports to Claude. Anything that fails is hidden for session 1, not redesigned (D-037); note it and carry on.

Setup steps are in [README.md](../README.md).

## 1. Cold start

- Run **Build Windows app**, unzip on the laptop, double-click.
- Pass: the DM window opens on the laptop screen, the table window fullscreen on the projector; Table setup's screen picker names the built-in screen "This laptop, in a window". Note the Windows display scale.
- Evidence: a phone photo of both screens.

## 2. Prep from nothing

- Calibrate with a ruler; import the Thundertree photo (10 ft a square); paint out the room numbers; import `data/monsters/mm2024.json` from the private library; enter the party; place the Thundertree groups hidden.
- Pass: one projected square measures 1 inch at the middle and at each corner; the map is 28 × 19 inches; no room number on the table; nothing about the hidden groups on the table.
- Evidence: a photo of the ruler on the grid; a photo of the whole projected map.

## 3. Three rounds

- Start the fight, type initiative, reveal one group, damage and heal monsters and a character, ping, pin, draw a lasting and a fading line, rub one out, turn the curtain on and off.
- Pass: letters, symbols and portraits read from each player's seat; the turn strip reads from both long sides; the HP ring changes on the DM map only; nothing DM-only on the table.
- Evidence: a photo from each long side with a mini on one token.

## 3b. Scenes (step 7k, D-039)

- Mid-fight, add a second scene with another map, switch to it with the minis still standing on the first map, then switch back.
- Pass: the curtain drops on each switch and nothing of the next scene shows before you lift it; clearing and replacing the minis takes under a minute; back on the first scene, the fight carries on from the same round with the same fog and discs.
- Evidence: a note of how long the minis took, and a photo of the table after switching back.

## 4. Things going wrong

- Close the app mid-round and reopen it. Then roll back to an older save (step 7g).
- Unplug the projector, then plug it back in.
- Copy a problem report (Table → Problem report).
- Pass: the app reopens on the same round, map and fog; the rollback works; with the projector unplugged the DM window stays usable, and after plugging back in the table returns to the projector with the same calibration (it is keyed to the Windows display id).
- Evidence: the problem report text, and a note of what happened at each unplug.

## 5. After

- List every failure and every slow moment. Claude sorts them into fix before session 1, hide for session 1, or after session 1.
